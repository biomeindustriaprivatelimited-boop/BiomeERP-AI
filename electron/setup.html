Connect to the Biome server

This PC is a client — all data stays on the server PC.

On the server PC open Settings → Server & Sync — it shows both addresses. Inside the office: the 192.168… address. Any other place: the office static IP (the same one you use for Remote Desktop). Port 4173 is added by itself.

After connecting, sign in with the user ID and password the developer/admin created on the server. If the server PC is off, this PC shows “Server connection lost” and reconnects by itself.
