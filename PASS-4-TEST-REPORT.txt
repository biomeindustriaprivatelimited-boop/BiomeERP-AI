BIOME ERP — IMPLEMENTATION PASS 4
=================================

Actual source changes in this pass:
1. GST Compliance now supports GSTR-2A (legacy inward statement) in addition to GSTR-1 and GSTR-2B.
2. GST Compliance now has a GSTR-3B Summary vs Books workflow with automatic column mapping and Excel export.
3. Delivery Challan UI now explicitly reflects Mouda 3-page / Solapur 2-page PDF output.
4. Delivery Challan Excel export date parsing now safely handles DD-MM-YYYY and ISO dates.
5. Offline receiving/lab confidence is strengthened when structured evidence is present:
   - Receiving: client + vehicle + date + weight => high confidence.
   - Lab report: client + vehicle + sample/document date => high confidence.
6. Existing FIFO receiving and lab-report date-range logic was regression-tested.
